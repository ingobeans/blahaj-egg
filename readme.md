# blåhaj egg

a mysterious egg appears on your desktop!! inside, a blåhaj!!

<img src=https://user-cdn.hackclub-assets.com/019fc392-f57f-7558-8314-4d2aaa80fcee/Screenshot%202026-08-02%20194249.png width=260>

## features: 

* you can pet the blåhaj ! 
* you can start a pomodoro timer (30 or 5 minutes). you get confetti upon completion :3
* a loving prescence in your life <3

## technical

made with rust and slint for UI.

to build yourself, you'll need rust installed. then you can just do 

```bash
cargo run
```

to build and run.
